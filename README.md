Hospital Management System in C

A simple console-based Hospital Management System developed using C programming language. The system helps manage patient records in a structured and organized way using a menu-driven interface.

Features

- Add new patient records
- View all patients
- Search patient by ID
- Simple menu-driven system

Technologies Used

- C Programming
- Structures
- Arrays
- Functions
- Modular Programming

Project Structure

- main.c → Main menu and program execution
- patient.c → Handles patient operations
- patient.h → Function and structure declarations
- utils.c → Helper functions
- utils.h → Helper function declarations

Key Learning Outcomes

- Basics of structured programming in C
- Working with arrays and structures
- Function-based program design
- Menu-driven application development
